# Reference art

The hand-drawn coat studies this project started from, in June, before the pet
was a composed sprite. Nothing loads them: every coat you see in the app is
recolored at draw time from one role-coded sprite (`src/cat-sprite.js`), and the
palettes live in `src/patterns.js`. There are eight studies against fourteen
shipped cat coats, so treat these as history and art direction, not a spec.

Painting a pose the composer cannot reach, and importing it, is a different
thing entirely and is documented in [../frame-pack.md](../frame-pack.md).
